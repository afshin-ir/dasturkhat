README
======
Lilak is an open source project for generating Persian dictionary for hunspell spell checker based on Persian Morphology.
This dictionary is free and the source is available under Apache License Version 2.0.



بررسی رسم‌الخط مرجّح در لیبره‌آفیس (آزمایشی)
=================================================

بستهٔ OXT لیبره‌آفیس یک بررسی‌کنندهٔ آفلاین هم دارد که صورت‌های نامرجّحِ برخی
قواعد دستور خط را در متن پیدا می‌کند و صورت مرجّح را پیشنهاد می‌دهد. در نسخهٔ
نخست، این بررسی شامل نیم‌فاصلهٔ پیشوندهای فعلی «می/نمی/همی» و پسوند جمع «ها»
است؛ برای نمونه «می شود» ← «می‌شود» و «کتابها» ← «کتاب‌ها».

برای دیدن زیرخط هنگام تایپ، بررسی خودکار دستور زبان در لیبره‌آفیس باید روشن باشد.
این بخش آزمایشی است و هنوز در Writer به‌صورت عملی بررسی نشده است.
